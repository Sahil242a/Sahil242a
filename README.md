I build AI systems that work on messy, real-world input — scam SMS in Hinglish, blurry number plates, handwritten answer sheets — and full-stack apps people can actually use, from real-time clinic queues to browser-to-browser file sharing. I care about measured accuracy, tested code and shipping things live.

🏆 **Winner of 2 national-level hackathons** — Google Gemini Buildathon and TechVriksha National Hackathon.
